# 🏆 Guide 10: Weekly Glory

The **Glory** page (**Glory Tracker**) keeps each member's Glory, week after week, so you can see who is progressing.

## ✍️ Enter this week's Glory

1. Open **Glory** (left menu).
2. Type each player's Glory in the **Input** column.
3. That's it: **it saves by itself**, a second after you type. There is no Save button.

You also see:
- **Previous week**: last week's value
- **Evolution (%)**: the change since last week, 🟢 up or 🔴 down
- **Guild Total This Week**: the sum for the whole guild

-# A week runs **Monday 00:00 UTC → Sunday**. On Monday, the page switches to the new week.
-# Clearing a box saves **0**. Leave it empty if the player really has no value yet.

## ⚡ Faster ways to fill it

- **With screenshots:** **Members** → **AI Metric Scanners** → **8. Glory OCR**. Scan your guild's Glory list, check, then **Validate & Apply**.
- **Players do it themselves:** in Discord, `/update-stats glory:4200`. It lands in this week's Glory Tracker.

## 🕰️ Fix a past week

The Glory page only shows the **current** week. To fix an older one: **History** → filter **Glory** → click the week → change the score.

## ❓ Good to know

- Glory does **not** count in the Reliability score (Guide 9). It's a separate ranking.
- A player with no value this week shows **-** in *Previous week* next week.
