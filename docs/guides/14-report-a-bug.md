# 🐞 Guide 14: Report a bug or suggest an idea

Found something broken? Tell the developer directly from the tool. It takes 2 minutes and helps everyone.

## How to report

1. Click **Report a bug** (🐞 bug icon, at the bottom of the left menu or in the top bar).
2. Fill in:
   - **Title**: one short sentence. *"Can't save Adelaide timezone"*
   - **Category**: *Bug*, *Feature request* or *Other*
   - **Severity**: *Low*, *Medium*, *High* or *Critical*
   - **Current Behavior / Issue**: what happens, with the **exact error message** if there is one
   - **Expected Behavior**: what should happen
   - **Steps to Reproduce**: click by click (optional, but very helpful)
3. Add up to **3 screenshots**: drag them in, or paste them with Ctrl+V / Cmd+V.
4. Click **Submit ticket**.

✅ You get a ticket number, like **#TICKET-0042**. Keep it!

## 💡 A great bug report

- **Copy the error message word for word.** It often points straight to the cause.
- **One problem per ticket.**
- **Say which page** and which button.
- **A screenshot** is worth a thousand words.

**Example (a real one, fixed the same day):**
> **Title:** Time Zone Setting Issue
> **Current:** "Error: invalid input syntax for type integer: '9.5'" when I set Adelaide (ACST/ACDT)
> **Expected:** the Adelaide time zone can be saved
> **Steps:** Members → Edit Member → Timezone: Adelaide → Confirm

## ❓ Good to know

- Only **admins and officers** can report bugs. Players: ask one of your officers.
- The tool has no "my tickets" page yet. To follow up, **quote your ticket number** to the developer on Discord.
