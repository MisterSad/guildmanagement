# FGF Guild Management: user guides

Short, step-by-step guides for guild leaders, officers and players. Each file is written to be **pasted into Discord**:
- one block between two `---8<---` lines = **one Discord message** (every block is under 2,000 characters);
- do **not** paste the `---8<---` lines themselves;
- lines starting with `-#` show as small grey text in Discord.
