# 🔑 Guide 2: Give your officers access

This guide shows how to give your R4s and co-leaders their own admin login.

**First, one rule:** nobody can look up a password later. Not you, not the other officers, not the developer. You can only **make a new one**. That is on purpose: it keeps your guild safe.

There are **two ways** to add an officer. Pick one.

## ✅ Way 1: Invitation code (recommended)

No password at all. Your officer signs in with their Discord account.

**You do:**
1. Open the tool and go to **Accounts & access** (left menu).
2. Find the card **Invite an Admin**.
3. Pick your guild, then click **Generate Invitation**.
4. A code appears (like `ABCDE-FGHIJ`). It is already copied for you.
5. Send it to your officer in a **private Discord message**.

**Your officer does:**
1. Open the tool and click **Sign in with Discord**.
2. Choose **I have a code**.
3. Paste the code and click **Redeem code**.
4. Done! From now on, they just click **Sign in with Discord**.

-# The code works **once**, for **7 days**. It is shown only once, so copy it right away. Your guild can have up to 5 unused codes at a time.

## 🔐 Way 2: Username + password

Use this if your officer does not want to use Discord.

**You do:**
1. Go to **Accounts & access**, then find the card **Create Account**.
2. Type a username for your officer (example: `HawkEye`).
3. Click **Generate Access**.
4. The new account appears in the list, **with its password visible**. It is already copied for you.
5. Send the username and the password to your officer in a **private message**.

⚠️ The password is shown **only this once**. If you leave the page, it is hidden forever.

**Your officer does:**
1. Open the tool.
2. Type the username in **Identifier** and the password in **Password**.
3. Click **Sign in**.

## 😱 "We lost the password!"

No problem. You cannot see the old one, but you can make a new one:
1. Go to **Accounts & access**.
2. Find the officer's account in **Active Admin Accounts**.
3. Click the 🔄 button (**Renew Password**).
4. A new password appears and is copied for you. Send it to your officer.

The old password stops working right away.

## 🔗 Switching an officer to Discord login

An officer who has a password can switch to Discord login:
**Sign in with Discord** → **I already have an account** → type the username and password → **Link and sign in**.

⚠️ This is **one-way**. After that, the password is deleted and they can **only** sign in with Discord.

## 🧹 Removing an officer

In **Accounts & access**, click the 🗑️ button on their account. They lose access immediately.

## ❓ Which code goes where?

- **Invitation code** → for **officers** → *Sign in with Discord → I have a code*
- **Guild Join Code** → for **players** → *Sign in with Discord → Join a guild* (see Guide 1)
- **`/link` code** (from the Discord bot) → for **players** → *Player Portal → Link Discord*. It only turns on the bot commands.
