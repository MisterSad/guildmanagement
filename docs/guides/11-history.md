# 🕰️ Guide 11: History, review and fix past events

The **History** page lists every past event. It's where you **fix mistakes** after an event has ended.

## 🔎 Find an event

Use the filters at the top: **All**, **SvS**, **GvG**, **Shadowfront**, **DTR**, **Arms Race**, **Glory**.

Each card shows the date (or week number), the opponent and the result for SvS / GvG (e.g. *vs 1062 · 4W / 2L*), the total score, and how many players took part.

## ✏️ Fix a mistake

1. Click the event's card.
2. A window opens with every player.
3. Change what's wrong: **Participated**, scores (per day for SvS / GvG), **Late**, **Excused**, **Sub Present** (Shadowfront), **Appointed** (DTR).
4. Each change **saves right away** ("*Updated successfully*").

-# Typing a score above 0 ticks **Participated** for you.
-# The Stats (Guide 9) update right away with your fix.

## 🗑️ Delete: be careful!

**Delete one event:** open it and click **Delete** at the bottom. All its scores and participations are **erased for good**.

**Delete a whole category:** with a filter selected (e.g. *Arms Race*), a **Delete Arms Race history (N)** button appears. It erases **every** event of that type, **including the one running now**. ⚠️ There is no undo.

-# Use it only to clean up test data, never for a normal fix: edit the event instead.

## ❓ Good to know

- The **%** on a History card is a simple "played / listed" count. The **Reliability** in Stats uses weights and excuses (Guide 9), so the two numbers can differ. That's normal.
- Deleting an SvS or GvG from History keeps its W / L days in **Stats → War record**.
