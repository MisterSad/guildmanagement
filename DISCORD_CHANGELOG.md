📢 **FGF Guild Management Tool Update — CHANG_V3.5.3**

Hey everyone! I added a proper way for guild leadership to get in touch when something's not right — a dedicated bug-reporting system that lands straight in my support channel, so nothing gets lost. 🛠️🐞

### 🐞 Report a Bug, Direct to Me
- **New "Report a bug" button** in the top bar for every guild leader (and server/super admins). Open it, write a short title and a description, pick a category and severity, and send.
- **Automatic ticket numbers** (`#TICKET-xxxx`) so we can always refer back to a specific report instead of describing it again.
- **Reaches me instantly** on my Discord support channel — every report is logged and tracked.

### 🎫 Backstage (for Super Admin)
- A new **Tickets** console lists every report from every guild, newest first, and lets me mark each one Open / Resolved / Closed so the status is always clear.

*Every report helps me make the tool better — thank you for flagging what you find! Fly safe out there!* ⚔️
