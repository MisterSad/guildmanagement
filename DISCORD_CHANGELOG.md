📢 **FGF Guild Management Tool Update — CHANG_V3.9**

Hey everyone! Small but useful one this time: the tool now supports the game's cross-server migration events. 🌐⚔️

### 🌐 Cross-Server Transfers, For Real This Time
- Whenever the game opens one of its periodic migration windows — grouping a cluster of servers together so players can move between them — I can now open a matching "migration window" in the tool.
- While a window is open, the **Transfer Member** button and the player's own transfer request in their Portal will show guilds on those other servers too, clearly marked **"Migration Window"** so it's obvious it's a special, temporary option — not your everyday same-server transfer.
- The player's full event history and stats travel with them automatically, exactly like a normal transfer.
- Once the game's window closes, I close it here too, and those cross-server options disappear — no leftover access after the event ends, even for a request that was still sitting in the approval queue.

*As always, thanks for the reports and feedback — keep them coming via the Report a Bug button!* 🚀🛡️
